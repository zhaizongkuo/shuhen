书痕 · 隐私政策

最后更新：2026-09-05 · English

书痕不收集你的任何数据，也不向任何服务器发送任何东西。
没有账号，没有后端，没有统计代码。

数据存在哪里

你的高亮、笔记、颜色，以及被高亮页面的标题和网址，全部保存在浏览器本地的 chrome.storage.local 里，只在这台设备上。

这里用的是 local 而不是 sync：sync 会把数据经由浏览器厂商的服务器 同步到你的其他设备，local 不会。所以你的高亮内容连浏览器厂商也拿不到。

卸载扩展时，浏览器会一并删除这些数据。

我们不做的事

  • 不向任何服务器发送数据（扩展代码里没有任何一处网络请求）
  • 不使用任何第三方统计、崩溃上报或广告 SDK
  • 不读取、不上传你的浏览历史
  • 不要求注册、不要求登录、不要求邮箱

权限说明

安装时，书痕不申请任何网站的访问权限。

权限用来做什么
storage把你的高亮保存在本地
activeTab你点击扩展图标时，临时获知当前页地址，以便向你申请该站点的授权
scripting把高亮功能注入到你已授权的站点
站点访问权限逐站授权。只有你在某个网站上点了扩展图标并同意，书痕才能在那个网站工作

你可以随时在 chrome://extensions（Edge 为 edge://extensions）中撤销任一站点的授权。

我们在你授权的页面上读什么

为了让高亮在页面刷新、改版、无限滚动之后仍能回到原处，书痕需要读取该页面的文本内容， 并记录你选中的那段文字及其前后各 32 个字符，用于重新定位。

这些内容只在你的浏览器内存和本地存储中使用，不会离开你的设备。

导出

导出 Markdown / 纯文本时，内容会写入你的剪贴板，或作为文件下载到你自己的电脑。 这个过程不经过任何服务器。

儿童隐私

书痕不收集任何数据，因此也不会收集儿童的数据。

变更

若本政策发生变化，会更新本页顶部的日期。若将来引入任何形式的数据上传， 会在扩展内明确告知并征得同意。
